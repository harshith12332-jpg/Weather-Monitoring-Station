# Weather Monitoring Station

## Objective
To monitor temperature, humidity, and light intensity using an Arduino Uno.

## Components Used
- Arduino Uno
- DHT22 Temperature and Humidity Sensor
- LDR (Light Dependent Resistor)
- 16x2 LCD Display
- Jumper wires

## Software Used
- Wokwi Simulator
- Arduino IDE / Arduino C++

## Working
The DHT22 sensor measures temperature and humidity, while the LDR measures light intensity. The Arduino Uno processes the sensor readings and displays the values on the 16x2 LCD. The readings can also be viewed through the Serial Monitor.

## Output
The system displays:
- Temperature in °C
- Humidity in %
- Light intensity

## Simulation
The circuit was designed and tested using the Wokwi simulator.
